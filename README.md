# wither
# 🌤️ Weather Pro Max - تطبيق الطقس الاحترافي

تطبيق ويب متطور لمتابعة حالة الطقس لحظة بلحظة، يتميز بتصميم زجاجي (Glassmorphism) وتجربة مستخدم سلسة.

## ✨ المميزات (Features)
* 🔍 **بحث ذكي:** ابحث عن حالة الطقس في أي مدينة حول العالم.
* 📍 **تحديد الموقع:** جلب بيانات الطقس لموقعك الحالي بضغطة زر.
* 👗 **اقتراح ملابس ذكي:** نظام برمي يعطيك نصيحة بنوع الملابس المناسبة لدرجة الحرارة.
* 📅 **توقعات لـ 5 أيام:** عرض حالة الجو والأيام القادمة بشكل منسق.
* 📱 **متوافق مع الجوال:** تصميم مرن (Responsive) يعمل على جميع الشاشات.
* 🎨 **خلفيات تفاعلية:** تتغير ألوان الخلفية تلقائياً بناءً على حالة الطقس (مشمس، غائم، ممطر).

## 🛠️ التقنيات المستخدمة (Tech Stack)
* **HTML5:** لهيكلة المحتوى.
* **CSS3:** للتنسيق والرسوم المتحركة والخلفيات المتدرجة.
* **JavaScript (ES6):** للتعامل مع الـ API والعمليات المنطقية.
* **OpenWeatherMap API:** لمصدر بيانات الطقس الحقيقية.
